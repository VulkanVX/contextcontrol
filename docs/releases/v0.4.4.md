# ContextControl v0.4.4

Fixes missing answers with thinking models and places matching photos beside individual entries.

- Named places and products can show a related photo beside their details. This works with numbered lists, bold-name sections and named table rows.
- The answer appears before optional photo searches. Matched entry identities persist in chat history. Roundup hero images and unmatched previews no longer form a gallery below the answer; citations remain compact links.
- Photo lookup is bounded to six entries and 30 seconds. A blocked or cancelled photo search preserves the completed answer.
- Basic HTML detail lists emitted inside Markdown entries render as formatted text; code examples remain literal.

- Thinking off now sends `think: false` to Ollama. Previously the setting was omitted, allowing models to enable thinking by default.
- A thinking-only response no longer counts as a completed answer. When thinking was enabled or unspecified, ContextControl retries once with thinking off and the same evidence. If no answer can be generated, the chat displays an error.
- Web evidence leaves more context space for the answer. Truncated replies keep their available text and show an incomplete-response notice.
- Tokens stream as they arrive, including a visible thinking status. Stop can interrupt a waiting stream read.
- Ollama's token counts and generation timings now appear correctly. Interrupted streams and server errors are reported as failures.

Validation: 31 local chat protocol checks, 131 research/photo checks, 96 UI checks, resolver smoke tests, chat-renderer checks, and live Qwen 3.5 4B inference at a 4,096-token context on a 4 GB GPU. The repeatable inference fixture produced a visible cited answer with 1,387 input tokens and 110 output tokens, streamed in 93 chunks. A real Google pizza search returned a visible answer after reading three pages and found three separately matched place photos. External browser checks are opt-in and separate from the repeatable fixture.

Protocol behavior follows the [Ollama chat API](https://docs.ollama.com/api/chat) and [thinking controls](https://docs.ollama.com/capabilities/thinking).
