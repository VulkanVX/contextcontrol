# ContextControl v0.4.0

Download **ContextControl-win-x64-Setup.exe** for Windows x64. It contains the full self-contained application and the PowerShell context engine.

## What's changed

- **Consistent interface scaling.** The UI size setting now scales text and custom controls together. Slider changes are coalesced, and settings writes wait until changes settle.
- **Readable large chat text.** Headers grow with the chat font; metadata and timestamps scale with it, with timestamps kept slightly smaller than the body.
- **Floating Chat Monitor.** Compact, draggable rows show request activity and available statistics. Open an exact chat, expand a quick reply with drag-and-drop attachments, or remove a row. New and continued chats are added automatically; history menus can add or remove them manually. Enable or hide it in Settings → Prompt Window.
- **Animated feedback.** Active chat status lines use pulsing dots and a moving highlight, with cached text and a shared timer. Hidden monitor windows suspend their animation.
- **Modern appearance.** Studio adds coordinated dark surfaces and soft accents. Workspace tabs have clearer text and wrap when space is tight; settings, message cards and monitor controls have updated spacing and shape. Existing appearance preferences are retained.
- **PowerShell-based Skillbook.** The release includes the Skillbook interface and documentation mapping its instruction sections to the bundled scripts.

The monitor follows conversations in the running ContextControl app. It preserves membership across restarts, and closes when the workbench exits.

## Validation

Release packaging runs the Workbench smoke suite and isolated UI regression checks, failing on any test or publish error. The UI harness renders the actual Avalonia views at normal and enlarged sizes and checks session routing, concurrent progress, drafts, attachments, persistence and animation lifetime without sending model requests.
