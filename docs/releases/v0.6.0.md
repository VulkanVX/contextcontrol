# ContextControl v0.6.0

Choose the operation explicitly with `/` actions, adapt the request context to the workload, and check generated browser games before playing.

- **Actions:** searchable slash menu, keyboard insertion, icons, and a separate library of descriptions, examples and requirements. `/search`, `/game`, `/chat`, `/image`, `/context`, `/run`, `/actions` use the existing application routes. Explicit search cannot be skipped by the model planner.
- **Context modes:** Adaptive, Fast (8K), Balanced (16K), Long (32K), Maximum fit and Custom, selectable in the composer and LLM settings. Adaptive estimates prepared input plus room for thinking/output and chooses a suitable allocation under the configured ceiling. Memory/model/server limits remain in force; large prompts get a clear capacity error instead of knowingly being truncated. The request budget is displayed.
- **Larger contexts:** custom ceilings and managed server configuration support up to 1,048,576 tokens where the model and memory permit it. Maximum fit uses the memory planner; unknown model limits remain estimates. Compatible runtimes use remaining request space for generation instead of an implicit 4K output cap. External servers still require reloading in their own application to change actual allocation.
- **Game checks:** run the final HTML in the offline Game Lab, capture startup and input-handler errors, ask the same model for up to two repairs, and rerun each correction. Preserve original/corrected artifacts and a validation report. Automatic checking can be disabled in Settings → LLMs. No inference deadline was added.

## Verification

Context/action regression tests cover adaptive growth, fixed presets, memory pressure, server ceilings, command parsing, explicit search, bounded repair, unavailable checks, cancellation, and artifact preservation. UI tests exercise slash filtering and insertion, action routing, context persistence and the action library. Real WebView2 checks detect the original Qwen Snake initialization bug and pass its repaired version, catch input-handler failures, and rerun a fixture repair through the browser.

The earlier 8,192-context Snake test was a controlled workload, not a stability ceiling. A saved Qwen 3.8 27B benchmark already completed short generation tests with a 32,768-token allocation; its tuned warm throughput was about 2.7 tokens/second. Those tests did not fill the entire window and cannot predict the speed or correctness of a long game-generation request. This release does not claim every generated game is bug-free or every model supports a million-token context.

Built locally. No GitHub Actions or additional model downloads.
