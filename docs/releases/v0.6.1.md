# ContextControl v0.6.1

The architecture graph now separates folder regions, node cards and active selection through softer colors, clearer typography and stronger focus outlines. The graph's layout, routing and node information are preserved.

- **Visual hierarchy:** softly tinted generation regions, rounded cards and slim folder accents. Folder selection now changes its fill as well as its outline. Titles and metrics stay readable with very bright or dark custom colors; zooming in increases both text sizes.
- **Graph controls:** labeled icons for Find, Export, packing, Fit layout and the tree panel. The toolbar wraps at smaller widths. Search fits its viewport, full node paths and metrics are available on hover, and navigation instructions sit in a footer that cannot cover nodes.
- **Project tree:** clearer spacing and type, copy/close controls and a metric guide, retaining the full project tree text and its horizontal/vertical scrolling.
- **Rendering:** cache generation palettes, tonal styles, fonts and unchanged metric strings. Selection keeps the text cache; bounded incremental eviction replaces clearing the whole text cache at capacity. Live version/LOC changes still update the cached label. Raster exports dispose their render target and SVG cards use the new tonal treatment.

## Validation

Before/after JSON exports match exactly for node identities, dimensions, positions, paths, metrics, parent/child links and edges in both packing modes and dark/light themes. UI checks cover desktop, compact and 150% interface scaling, search bounds and action hit targets. Color checks verify at least 4.5:1 title/metric contrast in normal, selected and hovered states, including black, white, red, yellow and blue generation colors.

Matched headless Skia runs with 132 and 737 displayed nodes reduced managed allocation during selection redraws by approximately 25–27%. Wall-clock frame timings varied between runs; this is not a claimed FPS increase or GPU benchmark. The 737-node fixture represents 3,000 input files with the existing per-parent aggregation limit retained.

Built and packaged locally. No GitHub Actions or model downloads.
