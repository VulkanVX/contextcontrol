# ContextControl v0.5.7

Large Ollama model downloads no longer stop at ContextControl's fixed 30-minute deadline. They continue for as long as bytes or stages are progressing.

- Use structured download events from Ollama instead of parsing CLI spinner output.
- Retry a stalled or interrupted transfer up to twice, resuming cached data. User cancellation and permanent server errors stop immediately.
- Report the real error, such as a missing manifest, authentication failure or interrupted connection.
- Exclude already cached bytes when calculating download speed; require explicit success before marking a model ready.

The stalled Qwen 3.8 27B download was resumed from approximately 8.56 GB of cached text weights without discarding its partial files. Regression checks cover transfers that outlast the inactivity window while still progressing, actual stalls, cancellation, partial-stream failures, retries and error messages.

Includes the measured speed tuner from v0.5.6. Built and tested locally without GitHub Actions.
