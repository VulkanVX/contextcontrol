# ContextControl v0.5.2

Research now works in the existing Browser workspace, and sourced answers have faster media delivery and a new reading view.

- Each research chat gets its own browser tab with independent page state. Switching tabs preserves the page, and closing a working tab cancels only that chat's request. The animated count beside **Browser** shows actual active research sessions.
- Expand **Browser actions** below the chat to see recent actions and page thumbnails. Click a preview to open its working tab. The toggle is also in **Settings → Prompt Window → Google research** and survives restart. Thumbnails are captured on navigation only while enabled.
- Start subject photos alongside answer generation. For lists, completed entry names can start their photo lookup while text is still streaming. Cached images are reused, and final completion reuses the same photo worker.
- Show delivered text immediately instead of replaying buffered chunks character by character. Actual streamed updates and waiting animations remain live.
- Use softer, roomier entry cards, clearer titles and larger responsive photos. Subject requests can show up to four sourced photos as a collage, with captions and links.
- Click **Article ↗** on a sourced reply to open a local reading page in Browser: overview, section navigation, entry photos, collages and references. Model text is rendered through the Markdown parser; raw scripts and unsafe links are not executed. The page identifies its text as an AI-generated synthesis.
- Keep the topic in every photo fallback query and check source context. This rejects the unrelated Pokémon, Steam-profile and card-game images observed in a Warcraft racials chat. Existing Warcraft replies also hide those mismatched saved photos. Uncertain matches may produce fewer images; no substitute picture is forced into an entry.
- Center **Model changed · A → B** between messages with a vector icon. A marker still appears only after sending a prompt with the new model.
- Keep all model sizes discoverable with **Show all**, and order **Newest** using the verified source-library listing when release dates are unknown. The catalog contains 544 entries, including Qwen3.8; no model weights are bundled or downloaded by this update.

Validation includes UI rendering, live text delivery, photo-topic regressions, catalog filters, saved preferences, native WebView2 tab isolation/cancellation, preview thumbnails, article anchors and a four-photo browser collage. Photo association uses source metadata and does not guarantee every model-generated fact is correct.

A direct-source live check with the existing Granite 3.3 2B model read Blizzard's WoW Forever article, delivered four cached source images beginning at 17 ms, and completed a text answer in 10.45 seconds. Google result retrieval was also exercised; one later query timed out awaiting readable results. Consent, verification and unavailable pages still require attention in the working browser tab.

Install the setup EXE or use **Check updates** in ContextControl. Existing chats, settings and model downloads are preserved.
