# ContextControl v0.5.1

Google research now keeps related photos with the text they illustrate, and reasoning is easier to read.

- Fix missing WoW Forever images: recognize WoW/World of Warcraft names, retain article illustrations inside aside elements, and read multiple images with publisher captions and section headings. Explicit subject requests may use a subject-specific logo; generic publisher logos, ads and newsletter promotions are excluded.
- Place an overview image after the introduction and matching section images beside the relevant text on wide windows, or below it in compact windows. Photos retain captions, source links, click-to-enlarge behavior and their associations in saved history.
- Give each venue its own photo lookup budget. A roundup can supply different venue photos when its image captions or sections identify those venues. Missing images leave the text intact.
- Remove recognized Google translation controls from search evidence. If the model mistakes a label such as “Išversti ŠĢ Puslapī” for a bar, check the answer once against the original sources and omit an entry that remains invalid.
- Render headings, bold, emphasis, lists and code in the reasoning pane, with immediate streamed updates. The compact thinking strip uses readable text instead of raw Markdown. Code retains its literal symbols.
- Show **Model changed · A → B** between messages only after a prompt is sent using a different model. Selecting a model alone does not create a marker. Transitions survive reopening the chat.
- Add vector icons to workspace navigation and reasoning indicators to the model picker and LLM catalog. Tooltips distinguish observed traces, runtime-advertised support, family expectations and unknown support. A model without a separate trace can still solve reasoning tasks; output depends on the model, runtime template and Thinking setting.

Validation covers native WebView2 extraction, Google evidence/photo regressions, history persistence, model-switch behavior, reasoning formatting, scrolling, and wide/narrow rendered layouts. Live Google tests with Granite 3.3 2B retrieved three images from Blizzard's WoW Forever article and photos for two separate Tallinn bars. One other venue did not yield an image. These tests verify retrieval and association; web evidence does not guarantee that every model-generated fact or citation is correct.

Install the setup EXE below, or use **Check updates** in ContextControl. The release contains no model weights, private chats, browser profiles or user settings.
