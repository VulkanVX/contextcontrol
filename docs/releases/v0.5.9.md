# ContextControl v0.5.9

Create a browser game in Local chat, then open **Game Lab** directly from the completed response. The new **Create game** mode asks for a complete offline HTML/CSS/JavaScript game and includes its previous source in follow-up requests.

- Play on a desktop or mobile-sized stage, edit highlighted source with line numbers, Run changes, Restart the previous run, or Stop it completely.
- View preview FPS and runtime errors, save the HTML or a full-resolution screenshot, and prepare an improvement/repair draft with the source and errors in the original chat.
- Preview generated code in an isolated browser frame with network, native host access, profile storage, popups and downloads blocked. Python, Unity, Godot and other native projects continue through the existing project/export workflow.
- Do not offer Run for reasoning-only snippets, incomplete streamed HTML or interrupted responses. Keep partial output on connection failure or user cancellation.
- Remove fixed Ollama and compatible-chat generation deadlines. Slow loading, thinking and generation continue until completion, user cancellation, or an actual runtime/connection failure. Managed runtimes also continue loading while their process remains alive.
- Open an exported game with `ContextControl.Workbench.exe --play-game path/to/index.html`.
- Serialize settings reads/writes and replace complete files, preserving preferences during concurrent reads. Rapid settings changes share one background writer.

Validated locally with parser/chat/runtime checks, compact and desktop layout checks, and a real WebView2 run covering keyboard input, canvas drawing, restart, stop, error-to-repair and browser isolation. Release builds use no GitHub Actions.

Qwen 3.8 27B completed a live Snake request with thinking enabled and 8,192 context after 777 seconds (1,582 output tokens, 2.1 tokens/second), continuing beyond the old 10-minute deadline. Its generated HTML needed a small local initialization repair before play; the original output was preserved. The repaired game loaded without runtime errors in Game Lab. This is one live model test, not a guarantee that generated games are bug-free.
