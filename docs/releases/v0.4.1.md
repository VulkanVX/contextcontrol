# ContextControl v0.4.1

Local chat models can now research the web through Google, including models without native tool calling.

- **Google auto** lets the selected model decide when to search, write a query, receive a ranked result list, select pages to read, and answer using their text.
- Up to six results and three page reads per request, with clickable source buttons saved in chat history.
- Planning, searching and page-reading status appears in chat progress and the floating Chat Monitor. The existing Stop button cancels research and generation together.
- Available in Raw chat, CC flow, Settings → Prompt Window, and Chat Monitor quick reply. Switch it off for chats without Google requests.
- Uses the built-in Windows WebView2 browser with no API key. Google may require consent or verification in its browser window. Unreadable pages are marked as snippet-only evidence.

See [Google research](https://github.com/VulkanVX/contextcontrol/blob/main/docs/GOOGLE_RESEARCH.md) for behavior, limits and validation commands.
