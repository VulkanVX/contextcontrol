# ContextControl v0.4.3

Chat answers now render rich Markdown and structured information cards, with source photo previews for Google research.

- Bold and italic text, headings, nested lists, quotes, task lists and comparison tables render as formatted content. HTML entities such as `&#x20;` display correctly; code retains literal syntax.
- Numbered entries with bold titles become information cards for places, reviews and other detailed lists. Names and supporting fields stay together; narrow comparison tables become labelled rows.
- Markdown links and numbered research citations are clickable. Text selection and copying use the displayed text.
- A place card uses a photo only when its cited source title identifies that place. General source images stay in the source list.

- Source cards use Google result thumbnails or images supplied by readable pages.
- Click a photo to enlarge it in the image viewer; click its caption to open the source page.
- Cards wrap in narrow chats, and captions scale with the chat font and truncate cleanly.
- Photos are downloaded and resized in the background with a six-second budget. Missing or blocked images leave a usable text source.
- Cached previews survive reopening chat history. Old cache entries can be pruned without removing their source links.
- Text-only models still receive text evidence; displaying photos does not imply that the model analyzed them.

Validation includes offline image-loading and history regressions, rendered narrow/large-font chat checks, and Windows WebView2 extraction checks.
