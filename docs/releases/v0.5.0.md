# ContextControl v0.5.0

Live reasoning now stays with its reply, and local chat works with more runtimes.

- A compact strip inside the assistant message shows incoming reasoning. Click it, the message's **Reasoning ↗** button, or the conversation's Reasoning button to open a resizable split pane. Reasoning is grouped by reply with its prompt and timestamp. The pane follows incoming text until you scroll up.
- Streaming reasoning preserves the transcript's measured height and the reader's scroll position. Real model reasoning appears immediately and survives completion or a stopped/failed answer.
- Chat history rows show elapsed time beside the loading ring and short stages such as **Loading**, **Thinking**, **Googling**, **Reading**, **Writing**, and **Photos**. Duration labels use whole seconds.
- **Settings → Prompt Window → Progress panel above terminal** can hide the extra chat progress panel. The conversation and sidebar still show progress.
- Explicit photo requests trigger Google lookup even if a small model initially declines to search. Standalone subjects no longer require the model to produce a list or table. Photos keep their source and subject association; image-search pages and generic roundup photos are excluded. A failed explicit photo lookup is stated in the reply.
- With **Google auto**, current-information requests override mistaken no-search plans. If an unresearched answer admits missing public knowledge, ContextControl searches, reads sources and generates a replacement answer once. Google off is respected; failed lookups preserve the draft with an explanation. Retrieved facts inform the reply and sources remain in history; model weights are not retrained.
- The catalog grows from 302 to **544 entries**. The shipped discovery snapshot verifies 443 tags across 240 families, with source links, weight sizes and conservative memory guidance. Hosted-only entries remain separate from local downloads.
- Chat can connect to llama.cpp, KoboldCpp, LM Studio/llmster, Transformers and other compatible servers. Settings provide discovery and persisted connections, plus managed install/start/stop controls for llama.cpp, KoboldCpp and Transformers.
- Managed runtimes default to CPU to save VRAM. The llama.cpp installer now finds real platform binaries when the latest GitHub release is only a pointer. Unsupported native platform installations are gated.

Validation includes protocol, research/photo, real-window binding, scroll-stability and renderer checks, plus real streamed generation with one compact model per newly tested runtime. A seeded unknown-answer recovery test used live Google, read NVIDIA's product page, generated a caption with Granite 3.3 2B and attached the matching RTX 5090 photo from NVIDIA. The [runtime guide](https://github.com/VulkanVX/contextcontrol/blob/v0.5.0/docs/LOCAL_MODEL_RUNTIMES.md) distinguishes tested backends from compatible but untested external servers. Model weights, user settings and chat history are excluded from the release payload.
